# NPW Backend

Express.js backend service with MongoDB integration.

## Prerequisites

- Node.js (v14+)
- MongoDB
- npm or yarn

## Installation

```bash
npm install
```

## Configuration

Create a `.env` file in the root directory:

```
MONGODB_URI=mongodb://localhost:27017/npw
PORT=5000
NODE_ENV=development
```

## Running the Server

```bash
npm start
```

### Seeding an admin user

You can create a default admin user (email: `admin@nexus.com`, password: `admin123`) for development with:

```bash
npm run seed-admin
```

### Cookie-based auth notes

- This project now uses an httpOnly cookie named `token` for session authentication. The cookie is set on successful `/api/auth/login` and `/api/auth/signup` and cleared by `/api/auth/logout`.
- In development the server sets the cookie with `sameSite: 'lax'` and `secure: false` for convenience; in production we use `sameSite: 'none'` and `secure: true` (HTTPS required).
- The frontend uses fetch with `credentials: 'include'` (configured in `npw-frontend/api/client.ts`) so cookies are sent with requests.

### CSRF protection

- The backend exposes a CSRF token endpoint at `GET /api/csrf-token`. The token is generated by `csurf` and should be requested by the frontend (credentials included) before performing state-changing requests.
- For state-changing requests (POST/PUT/DELETE), the frontend must include the header `X-CSRF-Token` with the token returned by `/api/csrf-token`.
- The frontend `npw-frontend/api/client.ts` is updated to automatically fetch and include the CSRF token for POST/PUT/DELETE requests.

Manual test note: `npw-backend/src/testCsrf.js` demonstrates the flow (login -> fetch csrf token -> POST with header). You can also test via a session in PowerShell as described earlier.
